## Контроль полноты лекций

## Домашние задания

### [[ДЗ-1|ДЗ-1 — теория по типам задач]]

Универсальные алгоритмы решения всех пяти типов заданий: смена порядка интегрирования, объёмы тел, выбор координат и исследование числовых рядов.

### Правило раздела ДЗ

Для каждого ДЗ в базе обязательно ведётся блок **«Решение»**. В нём решается выбранный пользователем вариант по теории, собранной именно для этого ДЗ. Для задач, где условие требует поясняющий рисунок, рисунок является обязательной частью решения. Новые варианты добавляются в тот же блок «Решение».

## Правила ведения базы

1. **Все содержательные темы и блоки лекций должны присутствовать в базе.** Контроль ведётся через [[00 — Карта лекций и контроль полноты]].
2. Сначала фиксируется тема и конкретная страница лекции, затем ищется соответствующее место в прикреплённых учебниках.
3. Для каждого определения, теоремы, признака или свойства указывается учебник-источник и конкретная страница PDF.
4. Формулировки теорем, условия и доказательства сохраняются максимально близко к учебнику; лекция определяет состав тем, но не заменяет учебниковую проверку.
5. Если в лекции есть пометка **«дописать»**, вопросительная пометка, оборванный вывод, незаконченная теорема, неполное доказательство или фрагмент с доски, такой блок обязательно завершается по учебнику.
6. Если в лекциях есть более сильная или иная формулировка, чем в учебнике, расхождение фиксируется в [[05 — Расхождения лекций и учебников]]; учебнику не приписывается неподтверждённое утверждение.
7. Если в учебниках проекта подтверждение не найдено, материал помечается как **«Только лекция»**. Дополнение по найденному внешнему профильному учебнику допустимо только при явной маркировке **«внешний учебник»**, с прямой ссылкой и без приписывания ему статуса источника проекта.
8. Формулы оформляются в синтаксисе Obsidian/MathJax: `$...$` в строке и `$$...$$` отдельным блоком.
9. Если геометрический смысл важен для понимания, материал сопровождается схемой или графиком из папки `images`.
10. Ссылки на доступные в репозитории лекции и учебники должны вести на конкретную страницу PDF через `#page=N`; для проверяемого онлайн-учебника — на конкретный раздел его официального сайта. Не публиковать заведомо неработающие PDF-ссылки.

11. **Иерархия книг:** сначала наиболее профильные учебники из актуального списка источников проекта. Для теории вероятностей — выпуск XVI «Теория вероятностей» МГТУ; для математической статистики — выпуск XVII; для случайных процессов — Миллер–Панков, дополнительно Свешников. Внешние источники допускаются только при явно обозначенном пробеле в книгах проекта.
