### 2026-10-06 — GitHub как каноническое хранилище

- Репозиторий `gregkorneev-BMSTU/terver` подключён как основное хранилище базы.
- Markdown-файлы и рисунки публикуются напрямую в ветку `main` после каждого обновления.
- Рисунки в GitHub хранятся в текстовом формате SVG, чтобы их можно было обновлять через GitHub-интеграцию без бинарной передачи.
- Для исходных PDF подготовлен Git LFS; сами PDF пока требуют однократного добавления в `sources/`, потому что текущая GitHub-интеграция не принимает локальные бинарные PDF как файл-вложение.
