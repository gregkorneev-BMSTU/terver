# Источники PDF

Эта папка предназначена для учебников и файла лекций, на которые ссылается база.

Ожидаемые имена файлов:

- `Власова — Ряды.pdf`
- `Воробьёв — Теория рядов.pdf`
- `Гаврилов, Иванова, Морозова — Кратные и криволинейные интегралы.pdf`
- `Демидович — Задачи и упражнения.pdf`
- `Лекции Тервер.pdf`

После добавления PDF ссылки вида `sources/…pdf#page=N` начнут открывать конкретные страницы прямо из базы.
- `ТВиМС_3с_ИУ5_M1_DZ.pdf` — исходный лист ДЗ-1 (30 вариантов).
- `Лекция.pdf` — дополнительная рукописная лекция по числовым рядам, 5 страниц; использована для дополнительной сверки базы.
- `ЧР и Краты Лекции.pdf` — полный 60-страничный рукописный конспект по числовым рядам, двойным и тройным интегралам и пределу по базе; полностью проаудирован 2026-10-06. Файл ожидается в Git LFS-папке `sources/` для работы прямых ссылок `#page=N`.

## Модуль II. Теория вероятностей

- **Тервер1.pdf**, 4 страницы, 12.10.2026 — первая рукописная лекция второго модуля. Загружена в текущий проект, но **пока отсутствует в GitHub**. Для работающих прямых ссылок на страницы PDF необходимо добавить бинарный файл в Git LFS-папку sources/.
- **Внешний проверочный учебник**: Оскар Левин, *Discrete Mathematics: An Open Introduction*, 4-е изд., [глава 3 (комбинаторика)](https://discrete.openmathbooks.org/dmoi4/ch_counting.html), [§3.4](https://discrete.openmathbooks.org/dmoi4/sec_counting-combperm.html), [§3.8](https://discrete.openmathbooks.org/dmoi4/sec_advPIE.html). Проверка проведена по онлайн-изданию; ссылка открывает соответствующий раздел.
- Профильный учебник по теории вероятностей от преподавателя пока **не приложен**. Нельзя приписывать доказательства этому отсутствующему источнику.
