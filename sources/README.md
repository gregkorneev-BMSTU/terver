# Источники PDF

Эта папка предназначена для учебников и файла лекций, на которые ссылается база.

Ожидаемые имена файлов:

- `Власова — Ряды.pdf`
- `Воробьёв — Теория рядов.pdf`
- `Гаврилов, Иванова, Морозова — Кратные и криволинейные интегралы.pdf`
- `Демидович — Задачи и упражнения.pdf`
- `Лекции Тервер.pdf`

После добавления PDF ссылки вида `sources/…pdf#page=N` начнут открывать конкретные страницы прямо из базы.
- `ТВиМС_3с_ИУ5_M1_DZ.pdf` — исходный лист ДЗ-1 (30 вариантов).
- `Лекция.pdf` — дополнительная рукописная лекция по числовым рядам, 5 страниц; использована для дополнительной сверки базы.
- `ЧР и Краты Лекции.pdf` — полный 60-страничный рукописный конспект по числовым рядам, двойным и тройным интегралам и пределу по базе; полностью проаудирован 2026-10-06. Файл ожидается в Git LFS-папке `sources/` для работы прямых ссылок `#page=N`.
