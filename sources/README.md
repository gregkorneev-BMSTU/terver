# Источники

В эту папку должны быть добавлены исходные PDF, на которые ссылается Obsidian-база:

- `Власова — Ряды.pdf`
- `Воробьёв — Теория рядов.pdf`
- `Гаврилов, Иванова, Морозова — Кратные и криволинейные интегралы.pdf`
- `Демидович — Задачи и упражнения.pdf`
- `Лекции Тервер.pdf`

PDF отслеживаются через **Git LFS** (см. `.gitattributes`), поскольку `Лекции Тервер.pdf` имеет размер около 96.5 МБ.

Ссылки в Markdown уже используют эти точные имена и формат `#page=N`, поэтому после добавления PDF переходы на страницы начнут работать без изменения конспектов.
