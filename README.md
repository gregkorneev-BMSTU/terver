# ТерВер — база знаний

Каноническая Obsidian/Markdown-база по материалам лекций. Теория и доказательства сверяются с прикреплёнными учебниками; полнота лекций контролируется отдельной картой.

- Главная точка входа: **База знаний.md**
- Веб-версия: https://gregkorneev-bmstu.github.io/terver/
- Автопубликация: Quartz + GitHub Actions + GitHub Pages

Каждый push в `main` автоматически запускает пересборку веб-версии.

## Приоритет источников

Формулировки и доказательства берутся прежде всего из **актуального набора книг, прикреплённых к проекту**. Для модуля II основной учебник — **«Теория вероятностей» МГТУ им. Н. Э. Баумана (2004), `06_Teoriya_veroyatnostey.pdf`**. Для математической статистики — одноимённый выпуск XVII МГТУ; для случайных процессов — Миллер–Панков и Свешников; для кратных интегралов — Гаврилов–Иванова–Морозова.

Внешние учебники допускаются только как явно помеченное **дополнение**, если нужный фрагмент не подтверждён проектными книгами. Перечень и приоритет изложены в `База знаний.md` и `sources/README.md`. PDF, доступные лишь как файлы проекта, нельзя выдавать за уже опубликованные в GitHub `sources/`.
