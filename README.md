# ТерВер — база знаний

Obsidian-база по материалам лекций. Лекции задают полный перечень тем, а формулировки, условия теорем и доказательства сверяются с прикреплёнными учебниками.

## Навигация

- **[База знаний.md](./База%20знаний.md)** — главное содержание.
- **[00 — Карта лекций и контроль полноты.md](./00%20—%20Карта%20лекций%20и%20контроль%20полноты.md)** — постраничная проверка покрытия всех лекций.
- `01…06` — крупные тематические файлы.
- `images/` — графики и схемы.
- `sources/` — учебники и лекции.

## Правило обновления

После каждого изменения базы обновляются соответствующие Markdown-файлы, карта покрытия и журнал изменений; затем изменения сразу фиксируются в ветке `main`.

## Источники PDF

Markdown-база и векторные рисунки уже хранятся в GitHub. Исходные PDF должны лежать в `sources/`; для них подготовлен Git LFS, поскольку один из файлов почти достигает лимита GitHub в 100 МБ.
