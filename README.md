# ТерВер — база знаний

Каноническая Obsidian/Markdown-база по материалам лекций. Теория и доказательства сверяются с прикреплёнными учебниками; полнота лекций контролируется отдельной картой.

- Главная точка входа: **База знаний.md**
- Веб-версия: https://gregkorneev-bmstu.github.io/terver/
- Автопубликация: Quartz + GitHub Actions + GitHub Pages

Каждый push в `main` автоматически запускает пересборку веб-версии.
